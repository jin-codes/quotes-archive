# Quotes Archive

마음에 남는 명언을 모아 두고, 무작위로 만나 보는 웹사이트입니다.

🔗 **https://quotes-archive.vercel.app**

## 주요 기능

- **Surprise me** — 명언을 무작위로 섞어 하나씩 보여 줍니다.
- **Favorite** — 마음에 드는 명언을 저장하고, 저장한 명언만 모아서 셔플할 수 있습니다.
- **언어 선택** — **KOR** / **ENG** 버튼으로 한국어 또는 영어 명언만 볼 수 있으며, 셔플도 선택한 언어 안에서 이루어집니다.
- **태그** — 주제별 태그로 명언을 골라 보고, 선택한 태그 안에서만 셔플할 수 있습니다.
- **다운로드** — 명언 목록을 xlsx 파일로 내려받을 수 있습니다.

> ⚠️ 비로그인 상태에서는 새로고침하면 모든 설정(언어, 태그, 즐겨찾기 등)이 초기화됩니다.

## 로그인하면

- 즐겨찾기 명언이 계정에 저장됩니다.
- 일반 계정은 명언을 직접 추가·수정·삭제할 수 없습니다. 대신 관리자에게 추가/편집/삭제를 **요청**할 수 있습니다.
