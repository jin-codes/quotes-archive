# Quotes Archive

마음에 남는 명언을 모아 두고, 무작위로 만나 보고, 이미지로 간직하는 웹사이트입니다.

🔗 **https://quotes-archive.vercel.app**

## 둘러보기 (로그인 없이 가능)

### 랜덤 명언 — Surprise me
- 화면 위쪽에서 명언 한 편을 크게 보여 주고, **Surprise me** 버튼을 누르면 다른 명언으로 바뀝니다.
- 셔플은 지금 선택한 **언어 · 태그 · 즐겨찾기 · 검색어** 조건에 맞는 명언들 안에서만 이루어집니다. (예: ENG + #용기 + 즐겨찾기만 → 그 조건의 명언만 셔플)
- 바로 직전에 나온 명언이 연달아 다시 나오지 않습니다.

### 언어 — KOR / ENG
- 한국어(KOR)와 영어(ENG) 명언을 버튼 하나로 전환합니다. 기본값은 KOR입니다.
- 언어를 바꾸면 지금 보던 명언의 **번역본**(같은 명언의 다른 언어 버전)이 있을 경우 그 명언으로 자연스럽게 넘어갑니다.

### 검색
- 명언 본문, 저자, 태그를 한 번에 검색합니다.

### 2단계 태그 필터
- 큰 분류(시작·희망, 용기·끈기, 삶·시간, 마음·지혜, 고통·위로, 관계·행복, 일·성공, 문학·철학, 기타)를 먼저 고르고, 그 안의 세부 태그(#용기, #끈기 …)를 여러 개 선택할 수 있습니다.
- 분류와 태그 옆에 명언 개수가 표시되며, 세부 태그는 많이 쓰인 순으로 정렬됩니다.
- 선택한 언어에 명언이 있는 분류만 보입니다.

### 고정(Pin)
- 명언 카드의 핀 버튼으로 마음에 드는 명언을 상단에 **고정**해 둘 수 있습니다. Surprise me를 누르면 고정이 풀리고 셔플로 돌아갑니다.
- 고정한 명언도 언어를 바꾸면 번역본으로 바뀌어 보입니다.

### 이미지로 저장
- 랜덤 명언 영역과 각 카드의 **이미지 저장** 버튼으로, 명언과 저자만 담긴 1080×1080 PNG를 내려받을 수 있습니다.
- 그라데이션 배경과 번들된 풍경·질감 사진 배경 중에서 고를 수 있고, 명언의 태그에 어울리는 배경을 먼저 **추천**해 줍니다.
- **내 사진**을 올려 배경으로 쓸 수도 있습니다. (올린 사진은 브라우저 안에서만 쓰이고 서버에 저장되지 않습니다.)
- 글이 길면 글자 크기가 자동으로 줄어듭니다.

### 내보내기 — Export .xlsx
- 명언 목록을 id, 명언, 저자, 분류, 태그, 즐겨찾기 여부, 언어, 추가일이 담긴 엑셀(.xlsx) 파일로 내려받습니다.

> ⚠️ 로그인하지 않은 상태에서는 즐겨찾기를 포함한 모든 설정이 새로고침하면 초기화됩니다.

## 로그인하면

- 이메일과 비밀번호로 가입·로그인할 수 있습니다.
- **즐겨찾기가 계정에 저장**되어 새로고침해도, 다른 기기에서도 유지됩니다.
- **명언 추가 · 수정 요청**: 일반 계정은 명언을 직접 바꿀 수 없고, 새 명언이나 수정안을 제출하면 관리자 검토를 거쳐 반영됩니다. 제출 화면에서는 태그를 직접 입력하거나 분류별 태그 중에서 고를 수 있고, 언어는 글자를 보고 자동으로 감지되며 직접 바꿀 수도 있습니다.
- 현재 삭제는 관리자만 할 수 있습니다.

## 관리자 기능

- **검토 대기열(Pending)**: 사용자가 보낸 추가·수정 요청이 쌓이고, 요청자 이메일과 함께 확인해 **승인 / 거절**합니다. 수정 요청은 원문과 수정안의 차이(diff)를 펼쳐서 볼 수 있습니다.
- 명언을 바로 추가·수정·삭제할 수 있습니다. (검토 없이 즉시 반영)
- **Import**: 엑셀 파일(.xlsx, .xls)로 명언을 한꺼번에 불러옵니다. 언어를 비워 두면 글자를 보고 자동으로 정합니다.
